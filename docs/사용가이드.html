1. 시작하기

접속과 로그인

  1. 사이트에 접속하면 첫 화면(환영 페이지)이 나타납니다.
  2. 오른쪽 로그인 창에 이메일과 비밀번호를 입력하고 [로그인]을 누릅니다.
  3. 계정이 없으면 [회원가입]에서 이름·이메일·비밀번호(8자 이상)를 입력해 가입합니다. 가입 즉시 선수(일반) 권한으로 이용할 수 있습니다.
  4. 화면 오른쪽 위 KO / EN 버튼으로 언어를 바꿀 수 있습니다. 기본 언어는 한국어입니다.

2. 일반 사용자 메뉴 (왼쪽 메뉴)

메뉴주요 기능
홈신청한 프로그램·예정된 상담·진행 중인 강의 요약, 최근 공지사항과 채용 추천을 한눈에 확인. 월간 캘린더 제공.
프로그램 신청[모집 공고]에서 프로그램을 선택 → 상세 확인 → [신청하기] → 지원 동기·경험 등을 입력해 제출. 이미 신청한 프로그램은 ‘신청 완료’로 표시됩니다.
나의 활동프로그램 신청 내역과 승인 상태, 상담 기록, 강의 수강 현황(진도율)을 확인합니다.
상담 예약[나의 활동 → 상담 예약]에서 ① 상담사 선택 → ② 날짜·시간 선택 → ③ 상담 주제와 방식(온라인/오프라인/전화) 입력 → ④ 확인 후 예약. 예약은 ‘예약됨’ 상태로 기록됩니다.
채용정보채용 공고 검색·상세 보기, 관심 공고 저장(★), 이력서 등록 후 공고에서 바로 지원.
학습자료[온라인 강의]에서 영상 강의 시청(YouTube·Vimeo·업로드 영상 모두 재생), 끝까지 보면 자동으로 ‘학습 완료’. [자료 다운로드]에서 문서 자료를 내려받습니다.
고객지원공지사항 확인, 자주 묻는 질문(FAQ) 검색, 1:1 문의 작성 및 [나의 문의]에서 답변 확인.

3. 지도자(코치)용 – 상담 가능 시간 게시

  1. 왼쪽 메뉴 [나의 활동 → 상담 일정 관리]로 이동합니다. (지도자·인사 담당자·관리자에게만 보입니다.)
  2. 주간 표에서 상담 가능한 시간 칸(30분 단위)을 눌러 선택합니다. ‹ › 버튼으로 주를 이동할 수 있습니다.
  3. [예약 가능 시간 게시]를 누르면 선수들이 즉시 예약할 수 있습니다. 예약된 칸은 초록색으로 표시됩니다.
문의: 플랫폼 관리자 · 이 문서는 사이트 기능 기준으로 작성되었습니다.

관리자 패널(CMS) – 사이트 관리 방법

관리자 · 인사 담당자 · 지도자용 · 2/2
이동: 왼쪽 메뉴 맨 아래 [관리자 패널]
기본 사용법(모든 관리 화면 공통): [추가] 버튼 → 입력 창 작성 → [저장]. 목록의 [수정]으로 내용 변경, [삭제]는 확인 창이 한 번 더 뜹니다. 저장 즉시 실제 사이트에 반영됩니다. [새로고침]으로 최신 목록을 다시 불러올 수 있습니다.

1. 첫 화면 꾸미기 – [배너 관리] (홈 화면 CMS)

  • 브랜드: 플랫폼 이름(국문/영문), 로고 이미지. [로고 업로드]로 이미지 파일을 올리거나 [기본 로고 사용].
  • 환영 문구: 상단 작은 문구, 메인 제목, 부제목.
  • 배경 영상: MP4 주소를 입력하거나 [배경 영상 업로드]로 영상 파일을 직접 올립니다. [영상 없이 사용]도 가능.
  • 로그인 영역: 로그인 안내 문구, 버튼 문구, 테스트 계정 안내(비워두면 숨김).
  • 글꼴 및 색상: 글꼴, 제목·부제목 크기와 색상.
  • 오른쪽 실시간 미리보기로 확인 후 반드시 [저장]을 눌러야 실제 첫 화면에 반영됩니다. [기본값으로]는 초기 디자인으로 되돌립니다.

2. 강의 및 영상 올리기 – [강의 관리]

  1. [강의 추가] → 강의 제목(필수), 영문 제목, 분류, 설명, 유형(영상/문서/퀴즈)을 입력합니다.
  2. 영상 넣는 방법 2가지: ⓐ YouTube·Vimeo·MP4 링크 붙여넣기, 또는 ⓑ [영상 업로드]로 PC/휴대폰의 영상 파일을 직접 업로드 (최대 500MB, 진행률 표시 – 업로드 중에는 창을 닫지 마세요). 완료되면 영상 URL이 자동으로 채워집니다.
  3. 필요하면 [문서 업로드](PDF·HWP·PPT 등, 100MB), [이미지 업로드](썸네일, 10MB)도 같은 방식으로 올립니다.
  4. [저장] → 선수 화면 [학습자료 → 온라인 강의]에 바로 나타납니다.

※ Supabase 무료 요금제는 파일 1개당 최대 50MB까지만 저장됩니다. 큰 영상은 Supabase 유료 요금제로 한도를 올리거나 YouTube(일부 공개) 링크 사용을 권장합니다.

* 인사 담당자는 선수·지도자 계정만 추가/수정할 수 있습니다. 화면 상단 [화면 편집]은 PC에서 카드 크기를 드래그로 조절하는 기능입니다(휴대폰은 자동 맞춤).

운영 팁: 모든 화면은 PC·태블릿·휴대폰 화면 폭에 맞춰 자동 조절됩니다. 휴대폰에서는 왼쪽 위 ☰ 버튼으로 메뉴를 엽니다. 문제가 생기면 https://agcomedu.vercel.app/api/health 에서 서버·데이터베이스 상태(“connected”)를 확인할 수 있습니다.
